# Burn
Leaves damage over time on the enemy. Every 0.5 seconds, inflict `burnDamage` on the enemy. Burn lasts on the enemy for `burnTimer` seconds.

## Properties
| property   | type   | unit    | meaning |
| ---------- | ------ | ------- | ------- |
| burnDamage | number | HP      | Damage dealt each tick. |
| burnTimer  | number | seconds | How long the burn lasts. |
