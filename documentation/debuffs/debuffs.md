# Debuffs
A debuff is an effect an enemy receives after being hit by a projectile. Weapons link to the debuff they apply (see [[weapons]]). Each debuff is its own note with its default values in frontmatter.

## Properties
Each debuff has its own properties; define them in the debuff's note.

| debuff   | element | effect                      |
| -------- | ------- | --------------------------- |
| [[burn]] | fire    | Damage over time            |
