# Chill
Slows the enemy down. Its move speed is reduced by `chillSlow` for `chillTimer` seconds.

## Properties
| property   | type   | unit     | meaning |
| ---------- | ------ | -------- | ------- |
| chillSlow  | number | fraction | How much move speed is removed (0.4 = 40% slower). |
| chillTimer | number | seconds  | How long the chill lasts. |
