### Debuff
Burn - leave damage overtime on the enemy.
Every 0.5 seconds inflict the burnDamange on the enemy.
burn lasts on the enemy for the duration of the burnTimer (in seconds).

#### Default Burn Values

| name       | value |
| ---------- | ----- |
| burnDamage | 2     |
| burnTimer  | 5     |
